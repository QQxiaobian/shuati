# 刷题宝 使用说明

PHP + MySQL 的多用户刷题系统：题库导入、五种练习方式、错题本、模拟考试（服务端判分防作弊）、搜题、题库分享与管理后台。数据集中保存在 MySQL 数据库中，多人共用、换设备自动同步。

## 部署（Docker，推荐）

只需一个 `docker-compose.yml`，无需手动 clone 代码或导入 SQL：首次启动时 Compose 会自动从 GitHub `docker` 分支下载源码构建镜像，并自动建库建表、创建默认管理员。需要已安装 Docker 与 Docker Compose v2。

1. 新建一个目录，放入本仓库的 `docker-compose.yml`（也可直接下载）：

   ```bash
   curl -O https://raw.githubusercontent.com/QQxiaobian/shuati/docker/docker-compose.yml
   ```
2. 启动：

   ```bash
   docker compose up -d --build
   ```

   首次会自动下载源码并构建镜像；以后直接 `docker compose up -d` 即可启动，无需重新下载。
3. 浏览器访问 `http://服务器IP:8870`，默认管理员 `admin / admin123`（登录后请尽快修改密码）。
4. 数据保存在 Docker 卷 `shutibao_db_data` 中，删除/重建容器不会丢失；仅 `docker compose down -v` 会清空。
5. 需要自定义密码时，在同目录新建 `.env`：

   ```dotenv
   DB_PASS=你的数据库密码
   ADMIN_PASSWORD=你的管理员初始密码
   ```

   修改 `ADMIN_PASSWORD` 只影响首次初始化，不会重置已有管理员密码。

> 不安装 Docker 时，继续使用下方 phpStudy 方式；Docker 部署无需访问 `api/install.php`。

## 部署（phpStudy 环境）

1. 安装并启动 **phpStudy**（https://phpstudy.cn 下载），在面板中启动 **Nginx/Apache** 与 **MySQL**。
2. 把本目录（`shutibao`）整个放到网站目录，或直接在 phpStudy 中新建网站指向本目录：
   - phpStudy 默认网站根目录一般为 `phpstudy_pro/WWW`，即放成 `phpstudy_pro/WWW/shutibao`。
3. 如修改过 MySQL 的 root 密码，编辑 `api/config.php` 同步修改（默认 `root` / `root`）。
4. 浏览器打开初始化页面：`http://localhost/shutibao/api/install.php`
   - 自动创建数据库 `shutibao` 与全部数据表；
   - 按页面提示点击按钮创建默认管理员 `admin / admin123`。
5. 打开 `http://localhost/shutibao/` 登录使用。局域网内其他电脑把 `localhost` 换成你的内网 IP 即可访问。

> 旧版（纯静态 localStorage）数据：首次登录新版后，系统会自动把本机旧题库迁移到服务器（仅迁移当前登录账号自己的题库与练习数据），迁移完成后清除浏览器旧数据。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 题库管理 | 新建/重命名/删除题库，逐题增删改，按章节/题型/难度浏览 |
| 表格导入 | 向导式导入 .xlsx / .xls / .csv，每个非空子表生成一个独立题库 |
| 练习 | 顺序 / 随机 / 专项 / **背题模式**，支持题型、章节、难度、答题结果、判断题答案五维筛选；可开启**答对自动下一题** |
| 背题模式 | 直接展示答案与解析，上一题/下一题翻阅，不判分、不记录答题历史 |
| 错题本 | 答错自动收录；连续答对 N 次（默认 2，可在后台调整）标记为已掌握；支持**按题库、题型筛选** |
| 模拟考试 | 自选题库范围、章节、难度、**各题型题量与每题分值**，倒计时、自动交卷、成绩报告；**可导出 Word 试卷（无答案版 / 含答案解析版，答案紧跟每题）** |
| 搜题 | 跨题库关键词搜索，**结果直接显示答案与解析**，可直接练单题 |
| 题库分享 | 指定用户分享或生成分享链接，他人登录后一键接受 |
| 管理后台 | 用户管理、内置题库上传、分享治理、系统参数、审计日志 |

## 表格导入格式与容错规则

导入向导共 4 步：上传并解析 → 逐个确认 → 逐行校验 → 确认导入。系统做了大量容错处理，常见"不规范"表格也能直接导入：

### 基本结构
- 每个非空子表生成一个题库，题库名默认取子表名（可改）。
- **表头行自动探测**：自动跳过文件大标题行，定位真正表头；也可在向导第 2 步手动调整。
- 重复的表头行、完全无内容的垃圾行会被静默跳过。

### 列识别
- 表头别名自动匹配：题干/题目/试题、题型/类型、答案、解析、章节/知识点、难度/难易等。
- 选项列支持三种写法：
  1. **A–F 各占一列**（列头可以是 `A`、`B`… 或"候选项A""选项A"等）；
  2. **一列内分隔**：换行、`|`、或 `A. xxx B. xxx` 形式；
  3. **整题单格**：整道题（含 `A. B. C.` 选项、`答案：X`、`解析：…`）写在一个单元格，系统自动拆题。
- 无法识别的列自动忽略；没有表头时按内容启发式兜底猜测。

### 题型与答案
- 题型列可写：单选/多选/判断/填空/简答（问答、案例、计算、识图、实操、名词解释等归入简答）；不填时按选项数量和答案形式自动推断。
- 答案写法兼容：`B`、`答案：B`、`正确/错误/对/错/√/×`；判断题答案写选项字母（A=正确选项文本）也能识别。
- 难度列兼容：简单/中等/困难、初级/中级/高级、★ 个数等写法。
- 自动降级修正：无选项的"单选"按对错答案转判断题；只有 1 个选项且答案为 A 的转判断/填空；无答案无选项的问答类按简答兜底导入。
- 选项文字重复时自动去重并同步重映射答案字母。
- 错误行可跳过，只导入有效行；导入前逐行列出错误原因。

## 背题模式

练习设置页选择「背题模式」后开始：
- 每题直接展示正确答案（选择/判断题高亮正确选项）与解析；
- 「只显示正确选项」开关：开启后隐藏错误选项，只保留正确答案，适合快速记忆；
- 上一题 / 下一题自由翻阅，最后一题点「完成背题」结束；
- 不判分、不写答题记录、不触错题回流，适合考前快速过题。

## 模拟试卷：题型与分值设置

生成试卷页（`#/exam/setup`）可对四种可自动判分题型分别设置：
- **题量**：从所选范围随机抽取，题量不足时会提示缺口并阻止生成；
- **每题分值**：支持 0.5 分步进，默认 单选 1 / 多选 2 / 判断 1 / 填空 2。

页面实时显示预计满分；及格线 = 满分 × 及格百分比。交卷后成绩报告按题型拆分显示"得分 / 该题型满分"，逐题解析标注每题分值。简答题不参与自动判分试卷。

**考试防作弊**：试卷由服务端生成，进行中的考试**不下发答案与解析**；交卷由服务端判分并回流错题，成绩可信。刷新页面或换设备可继续作答（作答实时保存到服务器）。

成绩报告页提供两种导出（均为 Word .doc 文档）：
- **导出试卷（无答案）**：纯试卷，判断题留"（　）"、填空题留下划线作答位，适合打印给他人作答；
- **导出试卷（含答案解析）**：每道题后面紧跟绿色的"答案"行与"解析"行。

导出的 .doc 可直接用 Word / WPS 打开、编辑、打印或另存为 PDF。

## 数据与隐私

- 全部数据保存在服务器 MySQL 数据库 `shutibao` 中，多用户共用、换设备自动同步；
- 密码以不可逆哈希存储；登录错误 5 次锁定 10 分钟；
- 进行中的练习进度保存在本机浏览器（`localStorage`），其他数据均在服务器；
- 分享采用服务端授权：题库所有者撤销后，接收方立即不可见。

## 技术栈

- 前端：原生 HTML/CSS/JS，hash 路由单页应用；表格解析使用 SheetJS（CDN 加载）。
- 后端：PHP（PDO）+ MySQL，REST 接口位于 `api/` 目录；首次部署用 `api/install.php` 一键建库建表。
