01产品定义

先明确这个产品为谁解决什么问题，以及什么结果算“完成了一次刷题闭环”。

1.1 背景与问题

备考用户和题库整理者通常已经拥有 Excel、CSV 形式的题库，但通用刷题工具对表格结构要求固定：标题行不能选、列不能映射、多个子表要拆成多个文件反复上传，导入失败时也看不到具体原因。结果是“有题库但用不起来”，或者需要手工整理成平台指定格式。

本产品以自托管、数据可控为前提，把“表格导入”做成可预览、可纠正的向导，并围绕导入后的题库提供练习、错题、考试、搜索和分享能力。产品参照考试宝的核心使用路径，但不复制其社区、课程或付费体系。

核心问题
  • 表格结构不统一，导入门槛高、失败成本高。
  • 题库散落在个人文件里，无法按章节、难度、错题等条件复用。
  • 题库分享依赖发文件，接收方无法直接练习，也无法撤回。
  • 自托管场景需要清晰的管理员与普通用户边界。
产品回应
  • 多子表导入 + 标题行选择 + 逐列映射 + 行级校验。
  • 一个题库内按五个维度组合筛选，错题自动沉淀。
  • 题库只读分享、链接可撤销；内置题库一键复制。
  • 管理员维护账号、内置题库与系统边界，不越权查看私有内容。

1.2 产品契约

一句话定义：用户把 Excel 子表导入为结构化题库，按条件刷题并形成错题复习闭环；题库可只读分享给其他用户，管理员维护账号与内置题库。
契约项定义
主要用户有备考需求的个人用户；其次是整理题库并分享给学生的培训老师，以及维护站点的管理员。
触发场景用户拿到一份或多份 Excel 题库，希望快速变成可在电脑和手机上刷的题，而不是逐题录入。
核心任务登录 → 上传表格 → 选择子表与标题行 → 映射字段 → 校验并生成题库 → 选择练习方式 → 查看错题与成绩。
完成条件题库成功保存且题量与导入结果一致；用户能按至少一个筛选条件开始练习；答题结果、错题和练习记录被正确保存。
信任基础导入前可预览、可纠错；答题过程不丢答案；题库分享可撤回；用户私有题库不被其他普通用户访问。

1.3 产品目标

目标用“用户能观察到什么”来描述，不设无法验证的量化指标。

目标可观察的完成结果
降低导入门槛一份含多个子表的文件可以在一个向导中处理；每个子表可独立选择标题行和映射列；无效行在写入前被列出，并说明行号与原因。
让练习可控用户能按题型、答题结果、判断题答案、章节、难度组合筛选，看到匹配题量；无匹配题时有明确空状态。
形成错题闭环答错自动进入错题本；错题练习中连续答对两次可标记“已掌握”；用户也可手动恢复或移出错题本。
让题库复用用户能基于选定题库与筛选条件生成模拟试卷；题量不足时得到具体缺口提示；题库可以只读分享并随时撤销。
边界清晰普通用户只能访问自有、共享和内置题库；管理员能管理账号与内置题库，但默认不读取用户私有题目内容。

1.4 目标用户与典型场景

用户典型场景关键诉求
个人考生拿到培训机构的 Excel 题库，想按章节和错题反复练，考前做模拟卷。导入快、手机上能刷、错题不丢、能看到成绩和解析。
题库整理者 / 老师整理多门课的题库，按子表组织，希望分享给同事或学生。多子表一次导入、字段可映射、分享可撤回、接收方不用再拿文件。
站点管理员在宝塔或群晖 Web Station 上部署，维护账号、内置题库和系统设置。账号可控、内置题库可更新、分享可治理、用户数据边界清楚。

02角色与权限

系统只有管理员和普通用户两类账号。权限按“自有、共享、内置、他人私有”四条数据边界划分。

2.1 角色定义

角色定义核心能力
普通用户 通过开放注册或管理员创建获得账号的个人用户。管理员也可以拥有自己的题库并参与刷题。 管理自有题库；导入、练习、模考、搜题；只读分享自有题库；查看共享与内置题库。
管理员 拥有站点管理权限的账号。安装时创建首个管理员；管理员可创建其他管理员，但至少保留一个可用管理员。 普通用户全部能力；用户管理、角色调整、密码重置、内置题库管理、系统设置、分享治理、审计日志。
账号状态：账号只有“正常”和“已禁用”两种状态。禁用后立即无法登录，现有登录会话失效，该用户发起的分享链接失效；题库、答题记录和错题数据保留。重新启用后，原分享链接不会自动恢复，需要重新生成。

2.2 权限矩阵

能力普通用户管理员
注册、登录、修改自己的密码允许允许
创建、导入、编辑、删除自有题库允许允许，仅限自有题库
练习、模考、搜题、查看错题自有 + 共享 + 内置副本同普通用户
只读分享自有题库允许允许
访问他人私有题库禁止默认禁止；仅排障模式可只读访问并留痕
编辑共享题库或内置题库原件禁止内置题库允许；共享题库仍只读
管理用户、调整角色、重置密码禁止允许
管理内置题库与分类禁止允许
强制撤销全站分享禁止允许
修改系统设置禁止允许
查看审计日志禁止允许

2.3 数据可见性

数据范围普通用户可见内容管理员可见内容
自有题库完整内容；可编辑、删除、分享、练习。完整内容，但只可管理自己的题库；不修改他人题库。
共享给我的题库完整题目内容；只读；可练习、模考、搜题；不可编辑、转分享、下载。同普通用户，除非管理员本人是分享接收方。
内置题库目录题库名称、分类、题量、简介、示例题；可复制到自己的题库。完整内容；可编辑、上下架、删除。
内置题库副本导入后视为自有题库，可编辑、分享、删除。仅能管理管理员自己导入的副本。
他人私有题库不可见，不出现在列表、搜索或分享选择器中。默认仅可见元数据（名称、题量、占用空间、分享状态），不可进入题目内容。

管理员排障模式：仅在处理用户报障、侵权投诉或数据异常时启用；需填写原因，系统记录操作人、目标题库、时间与原因。排障模式只读，不提供编辑和下载入口。[假设, TBD]

2.4 管理员保护规则

  • 系统至少保留一个状态正常的管理员；最后一个管理员不能被禁用、降级或删除。
  • 管理员不能禁用自己；如需停用，必须先由另一名管理员接手。
  • 普通用户不能通过注册获得管理员角色；角色调整只能由管理员执行。
  • 管理员重置密码后生成一次性临时密码，用户下次登录必须修改密码。

03核心对象与状态

统一对象名称和状态，避免后续功能各自定义“题库”“错题”“试卷”的含义。

3.1 核心对象

对象定义关键属性
账号登录系统的主体，拥有角色、状态和存储配额。用户名、昵称、密码、角色、状态、存储用量、创建时间。
题库一组题目的集合。一个导入子表生成一个题库；手动创建的题库也属于同一对象。名称、简介、所有者、来源（手动/表格导入/内置副本）、题目数、更新时间。
题目题库中的最小练习单位，包含题干、题型、选项、答案、解析、章节和难度。题型、题干、选项、正确答案、解析、章节路径、难度、排序号。
导入任务一次表格上传到生成题库的完整过程，包含所选子表、标题行、列映射和校验结果。文件信息、子表列表、标题行、映射方案、有效行数、错误行数、状态。
答题记录用户对某道题的一次作答结果，是练习报告和筛选“答对/答错/未做”的依据。用户、题目、作答内容、是否正确、作答时间、来源（练习/考试）。
错题项用户错题本中的一条记录，跟踪答错次数、连续答对次数和掌握状态。用户、题目、答错次数、连续答对次数、状态、最近答错时间。
模拟试卷按用户配置抽题并冻结题目内容的试卷快照。组卷配置、题目快照、总分、时长、及格线、生成时间。
考试记录用户对某份模拟试卷的一次作答，包含答案、得分和状态。试卷、用户、作答、得分、开始/交卷时间、状态。
分享题库所有者向其他账号或链接授予只读访问权的关系。题库、发起人、接收人/链接、权限、状态、创建时间。
内置题库管理员维护的官方题库模板，普通用户可复制到自己的题库。名称、分类、题量、简介、示例题、上架状态、更新时间。
审计日志记录管理员和系统关键操作的只读日志。操作人、动作、目标对象、结果、时间、原因（排障模式必填）。

3.2 状态与允许操作

对象状态含义与允许操作
导入任务 解析中系统正在读取文件与子表。用户可离开页面，任务在后台继续。
待映射文件解析完成，等待用户选择子表、标题行和列映射。可取消。
校验中系统逐行检查数据。不可编辑映射；可取消。
待确认 / 部分可导入校验完成。用户可查看有效与错误行，决定导入有效行或返回修改；零有效行时不可导入。
成功 / 部分成功 / 失败成功表示全部有效行已写入；部分成功表示有效行写入、错误行被跳过；失败表示未生成任何题库。均保留结果摘要与错误报告。
账号 正常可登录并使用全部角色权限。
已禁用不可登录；现有会话失效；分享链接失效；数据保留。管理员可重新启用。
分享 生效接收方可只读访问题库，进行练习、模考和搜题。
已撤销发起人或管理员主动撤销。接收方立即失去访问权。
已失效题库删除或所有者账号禁用后自动失效，不可恢复；仅重置链接时，旧链接失效，但已接受分享的用户不受影响。
错题项 未掌握默认错题列表可见；可进入错题练习。
已掌握错题练习中连续答对 2 次后自动进入；默认列表隐藏，可在“已掌握”筛选中查看与恢复。
已失效原题被删除或共享被撤销后，题目不可打开；用户仅可移除该记录。
考试记录 进行中计时中，答案逐题保存；可刷新恢复；交卷前可修改答案。
已交卷用户主动交卷；显示成绩与解析；不可再修改答案。
已超时交卷倒计时结束系统自动交卷；未作答题目按错误计分。
删除语义：题库删除是不可恢复操作（P1 再考虑回收站）。删除前必须二次确认并输入题库名称；删除后该题库的全部分享立即失效，错题和考试记录保留摘要但题目入口显示“原题已删除”。

04范围与优先级

P0 是最小可用闭环：能导入、能刷、能考、能搜、能分享、能管理。P1 只列会改变当前架构或数据模型的能力。

4.1 P0 范围

模块P0 交付内容完成标志
账号与权限注册、登录、退出、修改密码；管理员创建账号、禁用/启用、重置密码、调整角色。普通用户与管理员看到不同入口；禁用账号无法登录。
题库管理题库列表、详情、题目列表、手动新增/编辑/删除题目、题库重命名与删除。导入或手动创建的题库可打开并准确显示题量。
表格导入xlsx/xls/csv；多子表；标题行选择；列映射；类型推断；行级校验；部分导入；错误报告。一个文件中的多个子表可分别生成题库，错误行有明确原因。
练习与错题顺序、随机、章节、专项、错题练习；五维筛选；即时判分与解析；练习报告；错题自动记录与掌握状态。用户可选条件开始练习，答错自动进入错题本。
模拟考试按题库、题型、章节、难度组卷；题量校验；试卷快照；倒计时；自动判分；成绩与解析。可生成试卷并完成一次考试，交卷后得到分数与错题。
搜题在自有与共享题库中搜索题干、选项、解析；按题库、题型、章节、难度筛选；查看答案与解析。搜索命中且有权限的题目可查看并进入单题练习。
分享与内置题库指定用户分享、链接分享、只读权限、撤销；内置题库分类浏览、示例预览、复制到我的题库。接收方可只读练习；发起人撤销后立即失效。
管理后台概览、用户管理、内置题库管理、分享治理、系统设置、审计日志。管理员可完成账号与内置题库维护，关键操作有记录。

4.2 P1 候选

  • 题目批量编辑与追加导入
  • 题库版本合并与去重报告
  • 收藏、笔记、学习统计
  • 简答题自评计入模考
  • 分享有效期、访问密码、公开题库广场
  • 题库另存副本（共享题库）
  • 原生 APP 壳与离线题库
  • 邮件找回密码、第三方登录
  • 题目纠错与反馈
  • 回收站与恢复

4.3 明确不纳入本期

交易与会员

付费题库、订单、分佣、会员权益。

内容社区

发帖、评论、排行榜、直播课与问答。

AI 与监考

AI 出题/解析、人脸识别、防作弊监考。

不纳入不等于永远不做，而是当前 P0 不为其预留专门的数据结构或页面入口。

05核心流程

先看四条主流程和页面结构，再看可点击的关键交互演示。演示只表达交互与状态，不代表最终视觉稿。

5.1 信息架构

用户端
  • 登录 / 注册：账号入口；注册可由管理员关闭。
  • 首页：继续上次练习、我的题库、错题数量、最近考试。
  • 题库：我的题库 / 共享给我 / 内置题库三个标签页。
  • 错题本：跨题库错题、已掌握筛选、错题练习。
  • 模拟考试：组卷、考试记录、成绩与解析。
  • 搜题：按关键词与筛选条件查找题目。
  • 我的：资料、存储用量、修改密码、退出登录。
管理端
  • 概览：用户、题库、题目、存储与近期导入概况。
  • 用户管理：搜索、创建、禁用/启用、重置密码、角色调整。
  • 内置题库：分类、上传、编辑信息、上下架、删除。
  • 分享治理：查看生效分享、强制撤销。
  • 系统设置：注册开关、存储配额、上传限制、分享开关。
  • 审计日志：管理动作与排障访问记录。

5.2 表格导入流程

1上传表格选择 xlsx / xls / csv，解析子表。
2选子表与标题行每个子表可生成一个题库。
3映射列题干、题型、选项、答案、解析、章节、难度。
4校验预览有效行、错误行、重复题分别列出。
5生成题库写入有效行，保留错误报告。

关键约束：校验发生在写入之前；无效行不会被静默丢弃；用户可下载错误报告后修改原表再导入。

5.3 刷题与错题闭环

1选题库自有、共享或内置副本。
2设筛选题型、答题结果、判断题答案、章节、难度。
3作答提交后立即显示对错与解析。
4记录逐题保存答案；答错写入错题本。
5复盘练习报告、错题练习、连续答对标记掌握。

5.4 模拟考试流程

1配置试卷题库、题型题量、章节、难度、时长。

FR-01

账号与登录

目标：让用户建立可识别、可恢复、可管理的账号身份，并让管理员能控制谁能进入系统。

触发与入口

  • 未登录用户访问任意业务页面时，跳转到登录页；登录后回到原目标页面。
  • 注册入口仅在管理员开启“开放注册”时显示；关闭后登录页只保留登录与“联系管理员”提示。
  • 管理员可在后台直接创建普通用户或管理员账号。

注册字段与校验

字段必填规则
用户名是3–32 个字符；允许中文、字母、数字、下划线；不允许空格；全站唯一，英文不区分大小写。
密码是8–64 个字符；至少包含 1 个字母和 1 个数字；不允许与用户名相同。
确认密码是必须与密码一致。
昵称否1–30 个字符；用于页面展示和用户搜索；可重复。
邮箱否格式校验；P0 不发送验证邮件，不作为登录凭证；用于未来找回密码与通知。[假设, TBD]

登录与密码规则

  • 使用用户名 + 密码登录；错误提示统一为“用户名或密码错误”，不暴露账号是否存在。
  • 连续 5 次登录失败后，账号锁定 10 分钟；管理员可在用户管理中解除锁定。[假设, TBD]
  • 已禁用账号登录时提示“账号已停用，请联系管理员”，不进入任何业务页面。
  • 修改密码必须输入旧密码；修改成功后，该账号的其他登录会话全部失效。
  • 管理员重置密码后展示一次性临时密码；用户下次登录必须修改密码后才能进入业务页面。
  • P0 不提供邮件自助找回密码；忘记密码由管理员重置。P1 再增加邮件找回。[假设, TBD]

结果与异常

场景系统行为
用户名已存在注册提交失败，字段下方提示“用户名已被占用”；不创建账号。
密码强度不足提示具体缺失项（长度、字母、数字）；不清空已填写的用户名。
开放注册被关闭隐藏注册入口；直接访问注册地址时显示“注册已关闭”，提供返回登录入口。
账号被禁用或锁定显示对应提示；不创建登录会话；已有会话下一次请求时失效。
管理员重置密码生成临时密码；旧密码立即失效；用户首次登录被强制跳转到修改密码页。
FR-02

题库管理

目标：让用户看到自己拥有和可访问的题库，并能对题库与题目做必要的维护。

题库列表

“题库”页固定三个标签页：我的题库、共享给我、内置题库。三个标签页分别对应自有数据、只读授权数据和官方模板目录，不混排。

区域内容与行为
我的题库展示题库名称、来源标签（手动/表格导入/内置副本）、题目数、最近练习时间、分享状态。支持按名称搜索、按更新时间/题量排序。提供“新建空题库”和“导入表格”入口。
共享给我展示题库名称、所有者、题量、分享时间。只读；可练习、模考、搜题；可“移除共享”（只从自己的列表移除，不影响所有者）。
内置题库按分类浏览官方题库；展示题量、简介、更新时间、示例题；提供“导入到我的题库”。
空状态我的题库为空时显示导入按钮与“手动新建”两个入口；共享为空时说明“别人分享给你的题库会出现在这里”；内置为空时提示“管理员尚未上架内置题库”。

题库详情

详情页顶部显示题库名称、来源、题目数、章节数、分享状态与存储占用；主操作包括“开始练习”“模拟考试”“分享”“编辑信息”“删除”。题目列表支持按题型、章节、难度筛选，并显示题干摘要、答案是否完整、更新时间。

字段必填规则
题库名称是1–60 个字符；同一用户下允许重名，但列表中需可区分；导入时默认使用子表名，重名自动追加“(2)”。
题库简介否最多 300 个字符；展示在题库详情与分享预览中。
来源系统生成手动创建 / 表格导入 / 内置副本；用户不可修改。
题目数系统生成按当前题库内有效题目实时统计；删除题目后立即更新。

手动新增与编辑题目

  • 手动新增题目与表格导入使用同一套题目字段和校验规则；选项按 A–F 顺序填写，至少 2 个选项（判断、填空、简答除外）。
  • 题目编辑仅限题库所有者；共享接收方、内置题库浏览者不能编辑。
  • 删除单题需二次确认；删除后该题从题库移除，相关错题项变为“已失效”，已生成的试卷快照不受影响。
  • 内置题库副本视为自有题库，可编辑、分享、删除；原内置题库不受影响。

删除题库与权限边界

  • 仅所有者可删除自有题库；删除前必须输入题库名称确认，并明确提示“不可恢复、全部分享将失效”。
  • 删除后，题库从所有列表与搜索结果中消失；该题库的全部分享立即失效；相关错题与考试记录保留摘要，但题目入口显示“原题已删除”。
  • 共享接收方只能“移除共享”，不能删除、重命名、编辑或转分享题库。
  • 管理员不能编辑或删除普通用户的私有题库；仅可在排障模式下只读查看并记录审计日志。

异常与反馈

场景系统行为
题库为空详情页显示“暂无题目”，提供“继续导入”和“手动新增题目”入口；练习、模考按钮禁用。
题目被删除但仍在错题本错题项标记“已失效”，不可进入练习，只能移除。
存储配额不足禁止导入或新增；提示当前用量与剩余空间；已有题库不受影响。
共享被撤销时正在查看下一次请求跳转到“分享已失效”页；已生成的试卷快照仍可查看成绩，但不能开始新练习。
FR-03

表格导入

目标：把一份结构不统一的工作簿，在一次可检查的流程中变成多个结构化题库。导入是 P0 的核心能力。

入口、文件与子表

  • 入口：题库页“导入表格”、空题库页“继续导入”、管理后台“上传内置题库”。三处使用同一套导入向导。
  • 支持 .xlsx、.xls、.csv；CSV 支持 UTF-8 与 GBK 编码，系统可自动识别，识别失败时让用户手动选择编码。
  • 一个文件中的每个非空子表可生成一个独立题库。用户逐表勾选；未勾选的子表不进入导入。
  • 一个子表只支持一张连续的数据表：一个标题行 + 若干数据行。不支持同一子表内多个表头、合并多行表头或多张表拼接。
  • 空行自动忽略；只有部分列有值的行仍参与校验，不静默丢弃。

导入步骤

1上传并解析读取文件、子表、行列规模。
2逐个确认选择题库名、标题行、列映射。
3逐行校验错误、重复、类型推断结果。
4确认导入写入有效行，生成错误报告。

标题行与列映射

  • 标题行默认取子表第一条非空行；用户可在预览中改选任意一行，改选后下方数据预览即时刷新。
  • 系统按常见表头名称自动匹配；用户可覆盖任何匹配结果，或将某列设为“忽略”。
  • 一个系统字段只能映射到一个来源列；同一来源列不能重复映射给多个系统字段。
  • 每个子表独立保存映射；切换子表时，系统尝试复用上一张表的映射。表头不一致时必须由用户重新确认。
  • 导入前可修改每个子表生成的题库名称；默认使用子表名，重名自动追加序号。
系统字段必填映射与处理规则
题干是题目正文。去掉首尾空白，保留内部换行；同一题库内不允许题干完全为空。
题型条件必填可选：单选题、多选题、判断题、填空题、简答题。未映射时按“题型推断规则”推断；无法唯一推断则该行报错。
选项条件必填支持两种模式：分列选项（A–F 各映射一列）或单列选项（一列内用换行、| 或连续 A. B. C. 分隔）。两种模式不可混用。
答案是按题型归一化后校验；选择题答案必须是选项字母；判断题答案必须是可识别的对/错；填空题支持多个可接受答案。
解析否题目解析，可包含换行；为空时题目仍可导入，练习时显示“暂无解析”。
章节否章节路径文本，如“第一章 总论/第一节 宪法”；分隔符统一为 /。为空时归入“未设置章节”。
难度否归一化为简单 / 中等 / 困难；无法识别时归为“未设置”，不阻断导入。

题型推断规则

表格特征推断结果
有 2 个及以上选项，答案是 1 个选项字母（如 A）单选题
有 2 个及以上选项，答案是 2 个及以上选项字母（如 ABD）多选题
无选项或仅有“正确/错误”两项，答案是 对/错/正确/错误/√/×/T/F判断题
无选项，答案为非布尔文本填空题
无法唯一判断，或题型列写了系统不支持的类型该行报错，要求用户映射题型列或修改原表

简答题无法可靠推断，必须在题型列中明确写为“简答题/简答/问答”。[假设, TBD]

答案归一化

题型接受的写法归一化结果
单选题A、a、A.、（A）统一为大写字母；只能有 1 个答案；必须存在于选项中。
多选题ABD、A,B,D、A、B、D去重并按字母排序；至少 2 个答案；每个答案必须存在。

填空题一个答案，或用 | 分隔的多个可接受答案保留原文；比较时忽略首尾空格与英文大小写；其他字符按原样匹配。
简答题参考答案文本作为参考答案展示；P0 不自动判分，练习时由用户自评。

校验规则与错误报告

校验必须在写入前完成。系统逐行检查，错误不阻断其他有效行：用户可选择“导入有效行”或“返回修改”。

校验项判定与提示
题干为空错误：“题干不能为空”。
答案为空错误：“答案不能为空”。
选择题选项不足错误：“单选题/多选题至少需要 2 个选项”。
选项不连续或重复错误：“选项必须从 A 开始连续，且不能重复”。
答案不在选项中错误：“答案 X 不存在于选项 A–F 中”。
多选题只有 1 个答案错误：“多选题答案至少需要 2 个选项”；建议改为单选题。
判断题答案无法识别错误：“无法识别判断题答案，请使用 正确/错误/对/错/√/×”。
题型不支持错误：“题型 X 不支持，请使用单选/多选/判断/填空/简答”。
题库内重复题警告并默认跳过；按“归一化题干 + 题型 + 排序后的选项 + 归一化答案”判重。用户可查看重复清单。
字段超长题干或解析超过 5,000 字符、单个选项超过 1,000 字符时该行报错，不做静默截断。[假设, TBD]
整表无有效行阻止导入，提示“没有可导入的题目”；保留错误报告。

结果、状态与异常

场景系统行为

全部有效任务状态“成功”；所有选中子表分别创建题库；显示每个题库的名称与题量。
全部无效任务状态“失败”；不生成任何题库；保留错误报告供修改后重试。
文件损坏、加密或格式不支持解析阶段失败；提示具体原因（如“文件已加密”“不是有效的 xlsx”）；不进入映射步骤。
文件过大或超过子表数量上传前拒绝，提示限制值与当前值；不创建导入任务。详见 7.5
用户离开导入页解析、校验和导入在后台继续；用户可从“导入记录”回到任务查看进度与结果；已完成结果保留 30 天。[假设, TBD]
存储配额不足在校验完成、写入前检查；不足时阻止导入并提示剩余空间；已解析文件不写入题库。
关键原则：导入结果必须可解释。用户看到的“题量”必须等于导入摘要中的有效行数；任何被跳过或失败的行都要能在错误报告中找到原因。

目标：让用户按明确条件开始练习，提交后立即得到反馈，并让答错题目自动进入可复习的错题本。

练习入口与方式

入口在题库详情页与错题本页。进入练习前先展示筛选面板与匹配题量，用户确认后开始。练习方式如下：

方式题目范围顺序与恢复
顺序练习当前题库中满足筛选条件的全部题目。按题库内原顺序；退出后可继续上次位置，已答题保留。
随机练习当前题库中满足筛选条件的全部题目。开始前打乱一次；练习中不再变化；退出后不保证恢复原顺序。
章节练习指定一个章节路径及其子章节下的题目。按章节内原顺序；可继续上次位置。
专项练习按题型、答题结果、判断题答案、难度组合筛选的题目。默认原顺序；用户可切换随机。
错题练习错题本中“未掌握”的题目；可跨题库；可继续叠加题型、章节、难度筛选。默认按最近答错时间倒序；答对后按规则更新掌握状态。

五维筛选

筛选条件之间为“且”关系。筛选面板实时显示匹配题量；匹配为 0 时不能开始，并展示空状态。答题结果以该用户对该题最近一次作答为准。

维度可选值规则
题型全部、单选题、多选题、判断题、填空题、简答题按题目题型精确匹配。
答题结果全部、答对、答错、未做“未做”指该用户从未作答过该题；重新作答后以最新结果覆盖。
判断题答案不限、答案为“正确”、答案为“错误”仅在题型为判断题时生效；依据题目的正确答案，不依据用户作答。选择其他题型时该筛选项置灰。
章节全部、未设置、具体章节路径选择父章节时包含其子章节；章节来自导入字段，不单独维护章节树。
难度全部、简单、中等、困难、未设置按归一化后的三档难度匹配；“未设置”作为独立档位保留。

作答与即时反馈

  • 题面显示题型、章节、难度、当前进度；单选与判断题点击选项；多选题可多选；填空题输入文本；简答题输入文本并自行对照参考答案。
  • 用户点击“提交”后才判定；提交前可修改选项。提交后该题选项锁定，显示正确/错误、正确答案、解析、章节与难度。
  • 多选题采用全对得分，不做部分给分；判断题、单选题按唯一正确答案；填空题按 7.1 的文本比对规则。
  • 简答题不自动判分：提交后展示参考答案，用户选择“已掌握/未掌握”，结果计入答题记录，但不计入正确率；选择“未掌握”时可加入错题本。[假设, TBD]
  • 每答一题立即保存，不等练习结束；网络中断恢复后保留已提交答案。
  • 允许“跳过”：跳过记为“未做”，可继续下一题；练习结束前可返回作答。
  • 练习结束展示报告：总题量、已答、答对、答错、未做、正确率、用时、题目列表；提供“重练错题”和“返回题库”。

错题本规则

事件错题本变化
练习或考试中答错若题目不在错题本，创建“未掌握”记录，答错次数 +1；若已存在，答错次数 +1，连续答对次数归零。
在错题练习中答对连续答对次数 +1；达到 2 次时状态改为“已掌握”，从默认错题列表隐藏；未达到时仍显示“未掌握”。
在普通练习中答对只更新答题记录，不改变错题本的连续答对次数；错题仍需通过错题练习掌握。
再次答错连续答对次数归零；已掌握的题目重新变为“未掌握”。
手动“标记已掌握”直接进入已掌握状态；可在“已掌握”筛选中恢复为未掌握。
手动“移出错题本”删除错题项；之后再次答错会重新创建。
原题被删除或共享撤销错题项变为“已失效”，不可打开，仅可移除。

“连续答对 2 次”为默认阈值，管理员可在系统设置中调整。[假设, TBD]

练习记录与异常

场景系统行为
筛选无匹配题显示“当前条件下没有题目”，列出可调整的维度；不进入答题页。
练习中途退出已提交答案保留；顺序练习记录当前位置；再次进入时提示“继续上次练习 / 重新开始”。
刷新或断网已提交答案不丢失；未提交的选择不作为答题记录；恢复后从当前题继续。
题库在练习中被删除当前题可继续提交；下一题提示题库已删除，练习结束并保留已完成记录。
共享在练习中被撤销已加载题目可提交；下一题无法加载，提示“分享已失效”，练习结束。
简答题未自评报告中将该题标为“待自评”，不计入正确率，不影响错题本。[假设, TBD]
FR-05

模拟考试

目标：让用户按考试规则从多个题库抽题，完成一次有计时、有分数、有解析的模拟考试，并把错题回流到错题本。

组卷配置

配置项必填规则
试卷名称是默认“模拟试卷 + 生成时间”；用户可修改；1–60 个字符。
题库范围是可多选：自有题库、共享题库、内置副本。不能混合无权限题库；至少选择 1 个。
题型与题量是分别设置单选题、多选题、判断题、填空题数量；总题量为四项之和，至少 1 题。简答题在 P0 不进入自动判分试卷。[假设, TBD]
章节范围否默认全部；可选择多个章节路径；选择父章节时包含子章节。
难度范围否默认全部；可多选简单/中等/困难/未设置。
考试时长是1–300 分钟；默认 90 分钟。
及格线是按总分百分比设置，默认 60%；系统换算为及格分并四舍五入取整。
题目顺序是默认随机；题目顺序生成后固定。P0 不提供选项顺序打乱，避免答案字母与内容错位。

生成与校验规则

  • 生成前按“题库 + 章节 + 难度 + 题型”统计可用题量，并按题目内容去重；跨题库重复题在试卷中只出现一次。
  • 任一题型的可用题量少于设置值，均阻止生成，并显示“需求 / 可用 / 缺口”，精确到题型；用户可减少题量或放宽筛选。
  • 总题量为 0 或所有题库均无题目时，生成按钮禁用并提示原因。
  • 生成成功后创建试卷快照：保存题目内容、选项、正确答案、解析、题型、章节、难度与分值；之后题库编辑或删除不影响本卷。
  • 试卷总分 = 题目数量 × 1 分；每题 1 分，不设主观题加权。及格分 = 总分 × 及格线百分比，四舍五入取整。

考试过程

  • 倒计时由服务器时间控制，刷新、切后台、断网重连都继续计时；不以浏览器本地时间作为唯一依据。
  • 逐题保存作答；用户可在交卷前任意修改答案；未作答题目在交卷时按错误计分。
  • 交卷前显示确认弹窗，包含“未作答 N 题”；用户确认后交卷，答案锁定。
  • 倒计时结束时自动交卷，状态记为“已超时交卷”；未作答题目不得分。
  • 考试中页面显示总题量、已答、未答、剩余时间；题目导航可跳转，已答题有状态标记。

判分、报告与记录

结果项规则
自动判分单选、判断、填空自动判分；多选全对才得分；填空题按 7.1 文本规则。简答题不进入 P0 自动判分试卷。
成绩得分、总分、正确率、用时、是否及格；正确率 = 答对题数 / 总题数，保留一位小数。
题型拆分显示各题型的题量、答对、答错、未答与得分。
逐题解析可查看每题的我的答案、正确答案、解析；支持“只看错题”。
错题回流答错题目进入错题本；同一场考试中每题只记一次错误；连续答对次数归零。
考试记录按时间倒序展示试卷名、得分、状态、用时；可查看结果与解析；“再考一次”生成新随机试卷，不复用旧卷。

异常与边界

场景系统行为
题量不足阻止生成；给出每个题型的缺口；不清空用户已填配置。
考试中断网已保存答案保留；页面提示“连接已断开，倒计时继续”；恢复后继续答题，超时仍自动交卷。
考试中题库被删除或分享被撤销本卷为快照，可继续答题与查看成绩；但不能用该题库生成新试卷。
账号在考试中被禁用保存已提交答案；禁止继续答题；重新启用后可查看该场记录，但本场按超时规则处理。[假设, TBD]
未交卷就关闭页面考试记录保持“进行中”；再次进入可继续；超过结束时间后自动交卷。
重复点击交卷只产生一次交卷结果；重复请求返回同一成绩，不重复计错题。
FR-06

搜题

目标：让用户在有权访问的题库中快速定位题目，先确认题干，再决定是否查看答案。

搜索范围与查询

  • 搜索范围：用户自有题库 + 共享给用户的题库。内置题库目录按分类浏览，不混入题目搜索结果；内置副本视为自有题库。
  • 搜索字段：题干、选项文本、解析；不搜索答案字母本身，避免通过答案反查题目。[假设, TBD]
  • 关键词去除首尾空格；支持 1–100 个字符；多个关键词以空格分隔时按“且”匹配。
  • 英文不区分大小写；中文按原文匹配；不做拼音、同义词或模糊纠错。
  • 可叠加筛选：题库、题型、章节、难度；筛选项只展示当前用户可访问范围内存在的值。

结果与操作

区域内容与行为
结果摘要显示命中题数、关键词、当前筛选条件；结果分页，默认每页 20 条。
单条结果题干摘要（关键词高亮）、题型、章节、难度、所属题库、来源标签（自有/共享）。答案与解析默认隐藏。
查看答案点击后展开正确答案与解析，不产生答题记录；可再次收起。
练这题打开单题练习；提交后按普通练习规则记录答题结果并更新错题本。
定位题库跳转到所属题库详情并定位到该题；共享题库只读。

空状态与权限

场景系统行为
关键词为空不执行搜索，提示“请输入关键词”；不展示全量题目。
无结果显示空状态，建议减少关键词或放宽题库/题型筛选；保留已输入内容。
题库被删除或分享撤销该题库的结果立即从搜索中消失；已打开的题目下一次请求提示“内容不可用”。
搜索他人私有题库不会出现在结果中；即使构造请求也无法读取。
FR-07

分享与内置题库

目标：让题库在用户之间以只读方式流动，并让管理员维护一套可供所有用户复制的内置题库。

分享入口与方式

题库所有者可在题库详情页发起分享。分享对象是整个题库，不支持只分享单题或部分章节。P0 提供两种方式：

方式操作接收方体验
指定用户按用户名或昵称搜索站内用户，选中后确认分享；可一次选择多个用户。无需接受，题库立即出现在接收方“共享给我”列表；接收方也可主动移除。
分享链接生成唯一链接；链接可复制、重置、撤销。访问者必须登录后才能查看。打开链接看到题库封面与题量；点击“接受分享”后加入“共享给我”。链接本身不直接暴露题目内容。

分享权限与规则

能力发起人接收方
查看题目与解析允许允许
练习、模拟考试、搜题允许允许
编辑题库信息、题目、删除允许禁止
转分享给第三人允许（自己的题库）禁止
下载、导出、批量复制题目允许（自有题库）禁止
撤销分享允许仅可移除自己的访问
  • 分享为只读授权，不复制题库。发起人修改、追加题目后，接收方看到的是最新内容；发起人删除题库，分享立即失效。
  • 接收方从列表移除分享后，其已有的错题项与考试记录保留，但题目入口变为不可用；再次通过原链接访问时需重新接受（若分享仍生效）。
  • 分享链接默认长期有效，直到发起人撤销或重置；P0 不提供有效期与访问密码，P1 再增加。[假设, TBD]
  • 发起人账号被禁用时，其全部分享立即失效；重新启用后不自动恢复，需重新分享。
  • 管理员可查看分享关系并强制撤销，但不能把共享题库转为自己所有。
  • 分享不改变题库的存储归属与配额消耗；接收方不占用额外存储。

内置题库

  • 内置题库由管理员通过同一套表格导入向导上传，可归入一个分类；分类由管理员维护，未分类的题库归入“未分类”。
  • 普通用户在内置题库标签页按分类浏览，可搜索题库名称；卡片展示名称、分类、题量、简介、更新时间和 3 道示例题。
  • “导入到我的题库”执行复制：把当前版本的全部题目复制为用户自有题库，来源标记为“内置副本”，占用用户配额。
  • 副本与原内置题库相互独立：副本可编辑、分享、删除；管理员后续更新原题库，不会同步到已有副本。
  • 普通用户不能直接编辑内置题库原件，也不能把原件加入错题本；必须先导入副本或由管理员维护。
  • 管理员下架或删除内置题库后，目录中不再展示；已导入的副本不受影响。
  • 同一内置题库可重复导入，但系统需提示“已导入过”，由用户确认后创建新副本；副本名称自动追加序号。

异常与边界

场景系统行为
分享给不存在的用户搜索无结果；不能提交分享；不创建空分享记录。
分享链接未登录访问跳转登录页；登录后回到链接页；不向未登录用户展示题目内容。
链接被重置旧链接立即失效并显示“链接已失效”；已接受分享的用户不受影响，除非发起人撤销其访问。
接收方正在练习时分享被撤销当前题可提交；下一题提示“分享已失效”，练习结束并保留已答记录。
内置题库复制时配额不足阻止复制；提示所需空间与剩余空间；不生成不完整副本。
内置题库正在被复制时被下架已开始的复制可完成；新复制请求提示“题库已下架”。
FR-08

管理后台

目标：让管理员完成账号、内置题库、分享治理与系统设置，同时用审计日志约束管理行为。

概览

展示用户总数/正常/禁用、题库总数、题目总数、存储占用、生效分享数、近 7 天导入成功与失败数。所有数字可点击进入对应列表；不展示用户私有题目的具体内容。

用户管理

操作规则
搜索与筛选按用户名、昵称搜索；按角色、状态筛选；分页展示。
创建账号填写用户名、昵称、初始密码、角色；用户名唯一；创建后显示一次初始密码。
禁用 / 启用禁用后立即失效会话与分享；数据保留。不能禁用自己或最后一个管理员。
重置密码生成一次性临时密码；旧密码立即失效；用户下次登录强制改密。
调整角色普通用户 ↔ 管理员；不能把最后一个管理员降级；操作记入审计日志。
删除账号P0 不提供永久删除，只提供禁用，避免误删用户题库与记录。P1 再设计数据删除流程。

内置题库管理

  • 分类管理：新增、重命名、排序、删除空分类；删除分类前必须先把其中题库移到其他分类或下架。
  • 上传题库：使用导入向导，上传后可编辑名称、简介、分类、示例题；导入结果与普通导入一致。
  • 上架 / 下架：下架后普通用户目录不可见，已导入副本不受影响。
  • 删除：二次确认；删除后目录不可见，已导入副本不受影响；操作记入审计日志。

分享治理与系统设置

能力规则
分享列表查看题库名称、发起人、接收人/链接、创建时间、状态；可按题库或用户搜索；不展示题目内容。
强制撤销管理员可撤销任一分享；需填写原因；接收方立即失去访问；操作记入审计日志。
开放注册开关；关闭后仅管理员可创建账号。
存储配额设置每个普通用户的默认配额；调整后对新上传生效，已有数据不强制删除，但超额用户不能继续导入。
上传限制设置单文件大小、子表数量、单表行数、单次导入题目上限；不得超过部署环境的硬限制。
分享开关关闭后现有分享链接失效，用户不能新建分享；已生成的试卷快照不受影响。
错题掌握阈值默认连续答对 2 次；管理员可调整，调整后从下一次答对开始生效。[假设, TBD]

审计日志与管理员边界

  • 记录：账号创建、禁用/启用、角色调整、密码重置、内置题库上传/上下架/删除、分享强制撤销、系统设置修改、排障模式访问。
  • 每条日志包含操作人、动作、目标、结果、时间与原因（强制撤销和排障模式必填）；日志只读，管理员不能编辑或删除。
  • 审计日志默认保留 180 天，可由管理员导出；到期清理策略在部署时配置。[假设, TBD]
  • 管理员默认只能看到用户题库元数据，不能进入题目内容；排障模式为只读，需填写原因并留痕。
  • 管理员不能修改普通用户的题库、不能代替用户答题、不能把用户题库转给自己。

场景系统行为

管理员删除自己P0 无删除入口；禁用自己也被阻止。
调整配额导致用户超额用户已有数据保留；提示超额；禁止新增导入与内置复制，直到用量下降。

07共享业务规则

以下规则被多个模块引用，只在这里定义一次。功能章节不再重复定义评分、去重和配额。

7.1 答案比对与判分

题型判定规则练习反馈
单选题用户选择的选项字母与正确答案完全一致。正确/错误；显示正确答案与解析。
多选题用户选择集合与正确答案集合完全相同；少选、多选、错选均为错误；不做部分给分。正确/错误；显示完整正确选项集合。
判断题用户选择“正确/错误”与归一化后的正确答案一致。正确/错误；显示正确答案与解析。
填空题去首尾空格、英文不区分大小写后，与任一可接受答案完全一致；多个可接受答案以 | 分隔。正确/错误；显示全部可接受答案。
简答题P0 不自动判分；用户对照参考答案自评“已掌握/未掌握”。不算正确率，不自动进入错题本；自评“未掌握”时可由用户手动加入错题本。[假设, TBD]

考试中每题 1 分；未作答按错误计 0 分；多选不设部分分。正确率 = 答对题数 ÷ 总题数，保留一位小数。

7.2 难度与章节归一化

字段导入值示例归一化规则
难度简单、容易、低、1、2；中等、一般、中、3；困难、难、高、4、5统一为简单 / 中等 / 困难；数字 1–2 → 简单，3 → 中等，4–5 → 困难；无法识别 → 未设置。
章节第一章 总论 / 第一节 宪法；第一章 总论 > 第一节 宪法；第一章 总论 → 第一节 宪法分隔符统一为 /；保留层级文本，不自动创建章节管理页；筛选父章节时包含其子章节。

难度采用三档而不是五档，目的是让筛选和组卷更易理解；原始数字映射规则为产品判断，可在评审时调整。[假设, TBD]

7.3 去重规则

  • 题库内去重：按“归一化题干 + 题型 + 排序后的选项文本 + 归一化答案”生成判重键。同一题库中重复的题目在导入时默认跳过并计入重复数。
  • 跨题库：允许相同题目存在于不同题库；用户自己的题库之间不做强制去重。
  • 组卷去重：一次试卷从多个题库抽题时，按同一判重键去重，重复题在试卷中只出现一次。
  • 手动新增：保存时提示“可能重复”，由用户决定是否继续；不强制阻止。

7.4 权限、删除与生命周期

事件影响
删除题库题从所有列表和搜索中移除；分享全部失效；错题项变“已失效”；考试记录保留成绩摘要，题目入口显示“原题已删除”；操作不可恢复。
删除单题题库题量减少；该题错题项变“已失效”；已生成的试卷快照保留原题内容，可继续查看解析。
撤销分享接收方立即失去新访问权；进行中的练习在下一题结束；已生成的试卷快照仍可查看成绩；错题项变“已失效”。
禁用账号会话失效、分享失效；题库与记录保留；重新启用不恢复旧链接。
内置题库下架目录不可见；已导入副本不受影响。
共享题库更新只读接收方看到最新内容；已生成的试卷快照不更新。

以下为默认值，管理员可在系统设置中调整；具体数值需结合部署服务器的 PHP 上传限制、磁盘容量与备份策略确认。[假设, TBD]

7.6 时间、数据与隐私边界

  • 系统统一使用部署服务器时区（默认 Asia/Shanghai）记录时间；考试倒计时以服务器时间为准。
  • 密码只保存不可逆哈希，不以明文形式存储或展示；管理员重置时只展示一次临时密码。
  • 上传文件必须校验扩展名、实际文件类型与解析结果；文件名不直接作为存储路径。
  • 普通用户的数据边界在每次读取时校验，不能仅依赖前端隐藏入口。
  • 管理员排障模式、强制撤销分享、重置密码、调整角色必须写入审计日志。

08异常与边界

把最容易在开发阶段被忽略的失败路径列在一起，便于设计和测试逐项确认。

场景系统行为用户可见结果 / 恢复方式
上传文件损坏或加密解析失败，不创建导入任务。提示“文件已加密”或“不是有效的表格文件”；用户可重新选择文件。
所有行校验失败不写入任何题库。显示失败原因与错误报告；用户修改原表后重试。
部分行失败只写入有效行，任务标记“部分成功”。显示有效/错误/重复数量；可下载错误报告；题库可用。
导入重复题默认跳过，不打断导入。显示重复题数量与清单；用户可接受或修改原表。
存储配额不足阻止写入，不删除已有内容。提示所需空间与剩余空间；用户删除题库或联系管理员调整配额。
大文件或长时间导入后台执行，显示进度；用户可离开页面。从导入记录查看状态；失败可下载错误报告后重试。
练习筛选无结果不进入答题页。显示空状态与可调整的筛选维度。
模考题量不足阻止生成。显示每个题型的“需求/可用/缺口”；减少题量或放宽筛选。
考试断网已保存答案保留，服务器倒计时继续。提示连接断开；恢复后继续；超时自动交卷。
考试超时自动交卷，未答题按错误计分。成绩页标记“已超时交卷”；可查看解析。
分享被撤销新请求拒绝；已生成试卷快照保留。提示“分享已失效”；错题项标记失效；可移除记录。
账号被禁用会话失效，禁止登录与继续考试。提示联系管理员；数据保留，重新启用后可查看历史记录。
题目在原题库被删除错题项失效；试卷快照保留。错题本显示“原题已删除”；考试解析仍可查看快照。
搜索结果为空或关键词过短不展示全量题目。提示更换关键词或放宽筛选；保留输入内容。
最后一个管理员被降级/禁用阻止操作。提示“至少保留一个正常管理员”。

09运行约束与非功能要求

产品需要能部署在自有服务器上，通过浏览器和移动端稳定使用；不依赖第三方 SaaS。

9.1 访问方式与适配

Web 与移动端
  • 响应式 Web，覆盖桌面、平板和手机；手机端使用底部导航，桌面端使用侧边导航。
  • 提供可安装的 PWA：缓存应用外壳与静态资源，不要求离线做题；离线时提示网络不可用。
  • APP 访问在 P0 通过 PWA 或 WebView 壳实现，业务规则不变；不开发原生离线题库。[假设, TBD]
  • 支持现代 Chrome、Edge、Safari 与微信内置浏览器；不支持 IE。
部署形态
  • 自托管部署在宝塔、群晖 Web Station 等 PHP 环境；数据库与上传目录位于自有服务器。
  • 不依赖外部题库服务、对象存储或第三方账号体系；邮件服务为可选能力。
  • 建议启用 HTTPS；PWA 安装与安全的登录会话需要 HTTPS。
  • 备份由部署方负责，至少覆盖数据库与上传目录；系统不内置云备份。

9.2 性能与稳定性

  • 题库列表、题目列表与搜索结果分页展示，避免一次性渲染大量题目。
  • 大文件导入在后台执行并显示进度；页面刷新不丢失任务状态。
  • 考试倒计时、答案保存与交卷不受页面刷新影响；重复交卷不产生重复成绩。
  • 单个题库包含数千道题时，练习翻页、筛选和提交仍可正常操作；具体容量上限由部署环境决定。[假设, TBD]
  • 导入、考试交卷等关键动作需要防重复提交；失败时给出可重试的明确提示。

9.3 安全与数据保护

要求产品层约束
身份与会话密码不可逆存储；登录失败限流；禁用账号立即失效；修改密码使其他会话失效。
权限校验每次读取题库、题目、分享、考试记录时校验所有权或授权关系；不能依赖前端隐藏。
输入与上传校验文件类型与解析结果；限制文件大小、子表数与行数；避免将原始文件名直接用于存储路径。
常见 Web 风险防止 XSS、CSRF、越权访问与恶意文件上传；管理操作需要二次确认与审计。
隐私边界普通用户不能访问他人私有题库；管理员默认不读取私有题目内容；排障访问需填写原因并留痕。
数据恢复题库删除不可恢复；部署方应定期备份数据库与上传目录；P1 再考虑回收站。

9.4 可维护性

  • 系统设置项、错误提示、状态名称集中管理，避免不同页面出现互相矛盾的说法。
  • 导入错误报告中的字段名与界面字段名保持一致，方便用户对照原表修改。
  • 所有关键状态变化（导入、分享、考试、账号）在页面上有明确反馈，不只依赖日志。

10待确认问题

以下问题会改变产品边界或实现成本。当前文档已给出默认假设，评审时需要明确取舍。

编号待确认问题影响当前默认
Q1APP 是 PWA / WebView 壳，还是必须上应用商店的原生包？影响开发范围、推送能力、离线题库与审核成本。P0 用响应式 Web + PWA；WebView 壳作为可选交付；不做原生离线。

Q3分享是否长期有效？是否需要公开题库广场？影响分享治理、版权与内容审核。只读、需登录、默认长期有效；不提供公开广场。
